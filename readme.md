Catalogo de la vinateria "La Gran Bodega", donde el cliente podra buscar la bebida alcoholica de su preferencia.

El usuario puede consultar (GET), crear (POST), editar (PUT) y eliminar (DELETE) registros de la base de datos de productos y carritos de la vinateria.

Para mayor facilidad, se pueden cargar los registros a la base de MongoDB desde el archivo .csv adjunt en el repositorio.
